Action Guide

Langkah penyelamatan darurat berdasarkan situasi yang Anda alami. Centang setiap tindakan yang sudah dilakukan untuk memantau progres pengamanan akun.

0 dari 16 langkah selesai 0%
1. Baru menerima pesan, tautan, atau file mencurigakan +

Jangan membalas pesan, jangan mengeklik tautan, dan jangan membuka lampiran file berakhiran .apk.

2. Sudah terlanjur mengeklik tautan atau menginstal file .APK +

Putuskan koneksi internet segera agar aplikasi berbahaya tidak dapat meneruskan SMS OTP ke server pelaku.

3. Sudah terlanjur memberikan kode OTP, PIN, atau kata sandi +

Anda berpacu dengan waktu. Segera bekukan akses rekening sebelum saldo dipindahkan oleh pelaku.

4. Sudah terlanjur mentransfer uang ke rekening pelaku +

Jangan pernah mentransfer uang tambahan dengan alasan biaya pencairan atau pajak.
